# Agent Loop 추적

시나리오: `$ARGUMENTS` (비어 있으면 "사용자 메시지 하나가 도구 호출 한 번을 거쳐 최종 응답이 되기까지")

이 스킬은 코드를 고치지 않는다. 읽고 설명한다.

## 절차

1. 진입점을 찾는다: 인터페이스(CLI 또는 Discord)가 사용자 입력을 런타임에 넘기는 곳.
2. 시나리오를 따라 호출을 순서대로 추적한다. 추측하지 말고 실제 코드를 읽는다.
3. 단계마다 다음을 적는다.
   - 호출되는 함수와 위치 (`파일:줄`)
   - 이때 이벤트 로그에 쌓이는 이벤트
   - 메시지 목록(LLM 에 보낼 컨텍스트)이 어떻게 바뀌는지
   - 오류가 나면 어디서 잡히는지
4. 문서와 코드가 다르면 표시한다 (`docs/ARCHITECTURE.md` 기준).

## 출력 형식

```
1. interfaces/cli/...:12  사용자 입력 수신
   이벤트: UserMessage
   컨텍스트: [system, user]
2. core/loop.py:40        Provider 호출
   ...
```

끝에 한 문단으로 요약하고, 발견한 불일치나 의심스러운 지점을 따로 적는다.

아직 구현되지 않은 구간은 "미구현"이라고 적고 `docs/ARCHITECTURE.md` 의 설계를 대신 설명한다.
