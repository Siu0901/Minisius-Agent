# 보안 규칙

이 프로젝트는 사용자 컴퓨터에서 명령을 실행하는 에이전트를 만든다. 두 가지를 구분한다.

## 만드는 제품에 대해

- 권한 정책의 원본은 `docs/PRD.md` FR-07 이다. 기본값을 더 느슨하게 바꾸지 않는다.
- 작업 폴더 밖 수정, 삭제, 셸 명령은 승인을 거친다. 승인을 건너뛰는 경로를 만들지 않는다.
- 민감 경로(SSH 키, `.env`, `secrets.toml` 등)는 읽기도 차단한다.
- API 키와 토큰은 `secrets.toml` 에만 둔다. 이벤트 로그, 일반 로그, 오류 메시지에 남기지 않는다.
- Discord 메시지는 소유자 확인을 통과한 뒤에만 런타임에 전달한다.
- 문서의 규칙만으로는 부족하다. 차단은 `policy` 코드와 테스트로 강제한다.

## 개발하는 동안

- 실제 API 키나 토큰을 코드, 테스트, 문서, 커밋에 넣지 않는다.
- 테스트와 실험은 임시 폴더에서 한다. 사용자의 홈 디렉터리나 실제 `~/.minisius/` 를 건드리지 않는다.
- 의존성을 추가할 때는 왜 필요한지 말하고 `uv add` 로 추가한다.
