# 테스트 규칙

원본은 `docs/TESTING.md` 다.

- 새 기능에는 테스트를 같이 쓴다. 테스트 없는 기능은 `passes: true` 가 될 수 없다.
- 오류 경로를 검증한다: 잘못된 인수, 타임아웃, 재시도, 권한 거절.
- 기본 테스트는 네트워크와 실제 API 키 없이 돈다. LLM 은 가짜 Provider 로 대체한다.
- 파일을 건드리는 테스트는 `tmp_path` 안에서만 한다. 실제 `~/.minisius/` 를 쓰지 않는다.
- 테스트를 통과시키려고 테스트를 약하게 고치지 않는다. 테스트가 틀렸으면 왜 틀렸는지 말하고 고친다.
- "완료"라고 말하기 전에 `./scripts/verify.sh` 를 실행하고 그 결과를 그대로 전한다.
