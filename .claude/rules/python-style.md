# Python 스타일

- Python 3.12+. 패키지와 실행은 uv 로 한다(`uv add`, `uv run`). pip 를 직접 쓰지 않는다.
- 포맷과 린트는 ruff, 타입은 mypy strict. 설정은 `pyproject.toml` 이 원본이다.
- 모든 함수에 타입을 적는다. `Any` 와 `# type: ignore` 는 이유를 주석으로 남길 때만 쓴다.
- 입출력은 비동기로 쓴다. 비동기 함수 안에서 블로킹 호출을 하지 않는다.
- 설정과 경계 데이터(설정 파일, 도구 인수, 이벤트)는 Pydantic 모델로 정의한다.
- 주석은 코드가 말하지 못하는 이유를 적는다. 무엇을 하는지는 이름으로 드러낸다.
- 주석과 문서는 한국어, 식별자는 영어.
