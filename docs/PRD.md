# PRD — Minisius Agent

무엇을 만드는지의 원본. 구조는 [ARCHITECTURE.md](ARCHITECTURE.md), 순서는 [ROADMAP.md](ROADMAP.md).

## 1. 제품 정의

CLI와 Discord로 말을 거는 **설치형 범용 AI 에이전트**(미니 Hermes).

- 단일 사용자가 자기 컴퓨터나 서버에 설치하고, 본인 LLM API 키로 쓴다.
- 기존 에이전트 프레임워크 없이 런타임을 직접 구현한다.
- 가장 중요한 결과물은 그럴듯한 답변이 아니라, 작업을 계획·실행·검증하고 실패했을 때 안전하게 복구하는 시스템이다.

## 2. 완료 기준

- 준비한 과제 세트(20~30개)에서 재현 가능한 성공률을 기록한다.
- 위험 명령 차단, 중단 후 복구, 실행 과정 추적이 동작한다.

## 3. 범위 밖

다중 플랫폼(Telegram, Slack 등), 다중 사용자, 서브에이전트, SSH·클라우드 실행 백엔드,
음성, 이미지 생성, 브라우저 자동화, PostgreSQL·Redis·벡터 DB·Langfuse.

## 4. 기능 요구사항

완료 조건이 "미정"인 항목은 해당 버전을 시작할 때 채운다. 세부 기능 단위의 상태는
`.harness/features.json` 이 원본이다.

### FR-01 Agent Loop (v0.1)

사용자 요청을 LLM에 전달하고, LLM의 도구 호출을 실행해 결과를 다시 LLM에 전달한다.

완료 조건:
- 여러 번 연속 도구 호출, 한 응답 안의 여러 도구 호출을 처리한다.
- 최대 반복 횟수 제한이 있다.
- 도구 오류로 루프가 죽지 않는다. 오류는 도구 결과로 LLM에 돌아간다.
- 같은 도구가 같은 오류로 연속 3번 실패하면 멈추고 사용자에게 알린다.
- 최종 응답을 반환한다.

### FR-02 LLM Provider (v0.1)

`anthropic`, `gemini`, `openrouter`, `ollama` 중 사용자가 고른다.

완료 조건:
- 어댑터 3개(Anthropic, Gemini, OpenAI 호환)가 같은 Provider 인터페이스를 구현한다.
- 토큰 사용량을 표준 형태로 돌려준다.
- 도구 호출을 지원하지 않는 모델은 시작할 때 명확한 오류로 거절한다.
- 재시도 가능한 오류(429, 5xx, 네트워크)는 간격을 늘려 재시도한다.

### FR-03 Tool System (v0.1)

기본 도구: 폴더 탐색, 파일 읽기·검색·수정·생성, 셸 실행, 웹 검색·페이지 가져오기.
기억·스킬·예약 도구는 각 버전에서 추가한다.

완료 조건:
- 도구는 이름·설명·인수 스키마로 등록되고 LLM에 노출된다.
- 인수가 스키마와 맞지 않으면 실행하지 않고 오류를 LLM에 돌려준다.
- 파일·셸 도구는 실행 백엔드를 거친다.

### FR-04 이벤트 로그와 추적 (v0.1)

모든 LLM 요청·응답, 도구 호출 의도, 도구 결과, 승인, 오류를 append-only 로그에 남긴다.

완료 조건:
- 세션 하나의 전체 실행 과정을 로그만으로 재구성할 수 있다.
- 토큰과 비용을 세션 단위로 집계할 수 있다.

### FR-05 CLI (v0.1)

`minisius` 로 현재 폴더에서 대화를 시작한다. Discord와 동등한 정식 인터페이스다.

완료 조건: 미정

### FR-06 Discord 게이트웨이 (v0.2)

스레드 하나가 세션 하나. 설정에 등록한 소유자 계정만 허용한다.

완료 조건: 미정

### FR-07 권한과 승인 (v0.2)

| 동작 | 기본 정책 |
|---|---|
| 읽기·검색 | 전체 허용. 민감 경로(SSH 키, `.env` 등)는 차단 |
| 수정·생성 | 작업 폴더 안은 바로 실행, 밖은 승인 |
| 삭제·셸 명령 | 승인. "항상 허용"으로 등록한 명령은 예외 |

완료 조건:
- 승인은 CLI 프롬프트와 Discord 버튼이 같은 경로로 처리된다.
- 정책은 설정 파일에서 조정할 수 있다.
- 나머지: 미정
