# Minisius Agent

CLI와 Discord로 말을 거는 설치형 범용 AI 에이전트. 기존 에이전트 프레임워크 없이 런타임을 직접 구현한다.

- 무엇을 만드는가: [docs/PRD.md](docs/PRD.md)
- 어떻게 만드는가: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- 어떤 순서로 만드는가: [docs/ROADMAP.md](docs/ROADMAP.md)

## 개발 환경

```bash
./scripts/init.sh     # 의존성 설치와 환경 확인
./scripts/verify.sh   # 린트, 타입 검사, 테스트, 아키텍처 검사
```
